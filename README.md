## 💡 How to Use

### Search for Prompts
- Use the search bar to find prompts by keyword
- Search works across titles, categories, and prompt text

### Filter Results
- **Category** - Select a specific category
- **AI Model** - Filter by compatible AI (ChatGPT, Claude, etc.)
- **Difficulty** - Choose Beginner, Intermediate, or Advanced

### Copy Prompts
1. Click the **"Copy"** button on any prompt card
2. Or click **"View"** to see full details, then copy
3. Paste into your favorite AI tool (ChatGPT, Claude, etc.)
4. Replace placeholders like `[YOUR_TOPIC]` with your specific information

### Export Prompts
- Click **"Export to CSV"** to download filtered results
- Open in Excel, Google Sheets, or any CSV editor
- Perfect for organizing your favorite prompts

## 🎯 Best Practices

1. **Customize Placeholders** - Always replace `[BRACKETS]` with your specific information
2. **Iterate and Refine** - Use AI responses to improve your prompts
3. **Combine Prompts** - Mix and match prompts for better results
4. **Save Favorites** - Export prompts you use frequently
5. **Experiment** - Try different AI models for varied results

## 📝 Adding Custom Prompts

Want to add your own prompts? Edit the `PROMPTS_DATA` array in `index.html`:

```javascript
{
    id: 1000,
    title: "Your Custom Prompt Title",
    category: "Your Category",
    model: "ChatGPT",
    difficulty: "Intermediate",
    text: `Your prompt text here with
    - Bullet points
    - Instructions
    - Placeholders like [YOUR_TOPIC]`
}
```
